    📚 Catalog Source
    
                    
    
                        Browse Catalog ships with a bundled set of public-domain collections. To grow it without
                        rebuilding the app, host the catalog files on any static URL (GitHub raw, an object store,
                        any web server) and point here. Leave blank to use the bundled catalog.
                        This replaces the catalog source. To add individual third-party collections alongside the bundled set, use 🌐 Subscriptions above.
                        
                    
    

                    
    
                        
    
                            
                            
                            
    The base path that serves index.json + per-collection files. See Help → Remote catalog.
    
                        
    

                        
    
                            
                            
                            
                        
    
                    
    
                
    

                
                
    
                    
    ▶️ Default Collection (on reboot)
    
                    
    
                        A display reboots to whatever it was last showing. This is the fallback it uses when it has
                        no history yet — e.g. a brand-new wall display's first boot. Leave as “First non-empty”
                        to let it pick automatically.
                    
    
                    
    
                        
                        
                        
                    
    
                
    

                
                
    
                    
    🌙 Night & Quiet Hours
    
                    
    
                        Warms and dims the display in the evening so it doesn't glow like a mini-sun at night, then
                        brightens by morning — on a clock, no sensor. Optionally blanks (or powers off) the panel
                        overnight. E-ink displays ignore this (no backlight). Times use this device's clock.
